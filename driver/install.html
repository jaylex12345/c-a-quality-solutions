Install C&A Driver

Add the driver app to your phone so you can launch assigned jobs, send GPS updates, accept or reject work, and upload proof of delivery faster.

Open driver login Open dashboard

iPhone

  1. Open the driver login page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Confirm the name C&A Driver.
  5. Launch the app from the home screen icon.

Android

  1. Open the driver login page in Chrome.
  2. Tap the menu button in the browser.
  3. Choose Install app or Add to Home screen.
  4. Confirm the install prompt.
  5. Open the new C&A Driver icon from your home screen.
What stays the same Your existing Supabase login, session handling, assigned jobs, GPS updates, proof uploads, and logout continue to use the website driver account.
What changes The installable app gives drivers a more app-like launch experience on iPhone and Android while keeping the website URLs working.

If the browser does not show an install prompt, use the instructions above. The app still works from the website driver login page.
